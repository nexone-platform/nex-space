# outdoor assets

Outdoor props (trees, bushes, fountain, benches, lamp posts, paths) generated with
PixelLab. Follow the sizing/style rules in `docs/map-style-guide.md` (§2, §4-C).

Naming: kebab-case = asset key, e.g. `tree-round.png`, `fountain.png`, `bush-small.png`.
Props: 64×64 (large ones bigger), transparent background, top-down 3/4 view.
