# maps

Tiled maps (`.tmj`) exported from [Tiled](https://www.mapeditor.org/) live here and are
loaded by Phaser via `this.load.tilemapTiledJSON(...)`.

See `docs/map-style-guide.md` §7 for the layer structure and object conventions
(`floor`, `walls`, `decor-below`, `furniture`, `decor-above`, `collision`, `objects`).
