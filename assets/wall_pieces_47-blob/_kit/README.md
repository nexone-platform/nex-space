# Wall Kit — สร้าง 47-blob สไตล์ AI ใน Pixelorama

ชิ้น AI ที่คัดมาเป็น "ต้นแบบ role" + template ที่ tile ได้จริง สำหรับวาดผนัง 47-blob สไตล์ขาว+teal

## วิธีที่แนะนำ (เร็ว + tile ได้ชัวร์)
> **วาดทับ TEMPLATE ไม่ใช่เริ่มจากศูนย์** — geometry ของ template ถูกต้อง tile เนียนอยู่แล้ว

1. เปิด **`TEMPLATE_47blob.png`** ใน Pixelorama (นี่คือผนัง teal procedural — 47 tiles เรียงตาม index, ขอบเชื่อมตรงกันทุกชิ้น ✅)
2. เปิด **`INDEX-MAP_47blob.svg`** ไว้ดูข้าง ๆ — บอกว่าแต่ละช่อง #0–46 เชื่อมด้านไหน (N/E/S/W) + มุมไหน
3. เปิดชิ้น role ด้านล่างเป็น **reference สไตล์/สี** (จออีกหน้าต่าง หรือ import เป็น layer จาง ๆ)
4. ไล่วาดทับทีละ tile ใน template ให้เป็นลุค AI โดย **คงตำแหน่ง pixel ขอบที่เชื่อม** ตามเดิม (ห้ามขยับ) → ผนังจะยัง tile เนียน

## ⚠️ สิ่งที่ AI ไม่มี — ต้องวาดเอง
- **มุมนอก L (NE/SE/SW/NW)** — ชุด AI มีแต่ทรง 3D ใช้ไม่ได้ → วาดจาก template ช่องมุม (ดู INDEX-MAP) โดยเอาสไตล์จาก straight มาต่อเป็นมุม
- **inner-corner variants** (ช่อง #ที่มุมในเว้า) — วาดตาม template

## กติกาเหล็ก (เพื่อให้ tile เนียน)
1. **ด้านที่เชื่อม** (ตาม INDEX-MAP) ผนังต้องชนขอบ tile ที่ **pixel แถวเดียวกันเป๊ะทุกชิ้น**
2. ความหนาผนัง + ตำแหน่งเส้น teal ต้องเท่ากันทุก tile
3. เทสต์: เอา 2 tile ที่เชื่อมด้านเดียวกันมาวางชนกัน → ต้องเป็นเส้นเดียวไม่มีสะดุด
4. Export กลับเป็น atlas 8 คอลัมน์ 32px → แทน `walls-teal.png` ในเกมได้เลย (index ตรงกัน)
